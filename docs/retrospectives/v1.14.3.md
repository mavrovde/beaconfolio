## 6. Changes (enforcement order: hook > skill > charter > CLAUDE.md > command)

1. **charter (`release-manager`)** — the Scope step now forbids cutting the release PR while
   planned `release:vX.Y.Z` issues are open without an explicit owner de-scope, and names
   #411/#412 as the cost; the same step states that **an emergency/revert PR gets an expedited
   verdict BEFORE merge** — the #412 evidence.
2. **charter (`release-manager`)** — the Tag step switches to `gh api …/git/refs` + `gh release
   create` (a tag ref on an already-pushed SHA), recording the two measured failures of the old
   path: `gh release create --target <sha>` alone → HTTP 422, and a local `git push origin
   vX.Y.Z` buys the pre-push gate's empty-diff FULL round.
3. **skill (`lessons-learned` §70)** — `bump_version.sh` rotates the CHANGELOG itself; a hand
   rotation on top produces the double-heading state (measured during #428 prep), and
   `check_changelog_merge.sh` check 4 makes rotated entries **unrewordable inside the rotation
   PR** by design — reword before rotating or after releasing.
4. **playbook** — the mutation-check rule broadened from "a test that claims to pin a fix" to
   **any new control** (test, lint, workflow gate, alarm, eslint rule): it ships with the
   demonstration it can fail, stated in the PR body. The 9 class-G findings above are the
   recurrence evidence; lessons §69 carries the method.
5. **skill (`lessons-learned` §71)** — CodeQL default-setup runs cannot be re-run (`gh run
   rerun` → "cannot be retried", rerequest → 404/403); only a new commit triggers fresh
   analysis, and a single-SHA red with no error text is an upload fault, not a regression.
6. **Fix-forward actions taken by this retro, not carried as debt:** the retrospective review
   on #412; the #409 comment adding the second measured cadence instance; the three back-filled
   board rows.

**Deletions:** none. Nothing in the config fired wrongly this window; the two controls that
false-fired (#391's check 4 at v1.14.2, pr-evidence now) already have their fixes recorded
(shipped / #424).
